Parallax Effects

Floating Shapes

The background features three floating gradient shapes with blur effects that animate smoothly in a loop.

@keyframes float { 0%, 100% { transform: translate(0, 0) scale(1); } 33% { transform: translate(30px, -30px) scale(1.1); } 66% { transform: translate(-20px, 20px) scale(0.9); } } .floating-shape { animation: float 20s ease-in-out infinite; filter: blur(80px); opacity: 0.6; }

Mouse Tracking Parallax

The entire parallax layer follows your mouse movement with smooth easing.

document.addEventListener('mousemove', (e) => { mouseX = (e.clientX / window.innerWidth - 0.5) * 2; mouseY = (e.clientY / window.innerHeight - 0.5) * 2; }); function animateParallax() { currentX += (mouseX * 20 - currentX) * 0.05; currentY += (mouseY * 20 - currentY) * 0.05; parallaxLayer.style.transform = `translate(${currentX}px, ${currentY}px)`; requestAnimationFrame(animateParallax); }

Animated Grid Pattern

An animated grid that continuously moves to create depth.

.grid-pattern { background-image: linear-gradient(rgba(255, 255, 255, 0.05) 1px, transparent 1px), linear-gradient(90deg, rgba(255, 255, 255, 0.05) 1px, transparent 1px); background-size: 50px 50px; animation: gridMove 20s linear infinite; } @keyframes gridMove { 0% { background-position: 0 0; } 100% { background-position: 50px 50px; } }

Performance Optimizations

GPU Acceleration

Force GPU rendering for smooth 60fps animations:

.gpu-accelerated { transform: translateZ(0); backface-visibility: hidden; perspective: 1000px; }

Will-Change Property

Hint to the browser about upcoming animations:

.parallax-layer { will-change: transform; }

Custom Easing Functions

Smooth, natural-feeling transitions:

:root { --ease-smooth: cubic-bezier(0.4, 0, 0.2, 1); --ease-bounce: cubic-bezier(0.68, -0.55, 0.265, 1.55); } .element { transition: all 0.3s var(--ease-smooth); }

RequestAnimationFrame

Use RAF for smooth JavaScript animations:

function animate() { // Update animation values element.style.transform = `translate(${x}px, ${y}px)`; requestAnimationFrame(animate); } animate();
